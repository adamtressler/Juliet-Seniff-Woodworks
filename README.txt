# Juliet Seniff Woodworks — first website draft

This is a static HTML/CSS/JavaScript landing page draft. It is safe to preview locally and does not modify the existing julietseniff.com website.

## Preview
Open `index.html` in a browser. An internet connection is needed to load the optional Google Fonts; system fallbacks are included.

## Files
- `index.html` — page content and image selections
- `styles.css` — layout, typography, responsive styles
- `script.js` — hero slideshow
- `assets/` — compressed images used by the page
- `originals/` — source photos and video clips, preserved for future selection

## Before publishing
1. Replace the temporary About copy with Juliet's preferred introduction.
2. Add a real contact email and/or Instagram link.
3. Replace the current images with higher-resolution originals when available.
4. Review photo captions and image order with Juliet.
5. Confirm permission to publish any photos that include other people or client spaces.
